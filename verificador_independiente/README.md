Este módulo permite comprobar de manera independiente
los resultados de las consultas realizadas en redes bayesianas.

- Validar redes bayesianas.
- Calcular probabilidades mediante eliminación de variables.
- Comparar resultados mediante enumeración exhaustiva.
- Detectar errores en las tablas de probabilidad condicional.

Desde la carpeta principal del proyecto ejecutar:

python -m verificador_independiente.pruebas_motor
